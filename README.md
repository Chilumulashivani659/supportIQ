# SupportIQ

SupportIQ is an AI-powered customer support assistant designed to help support teams analyze customer issues, provide recommended actions, and generate customer-friendly responses.

## Features

- Customer support issue analysis
- AI-generated recommended actions
- Customer-friendly response generation
- Customer memory and interaction history
- Previous interaction tracking
- Analytics dashboard
- Support settings and help section
- Frontend and backend integrated in one project

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- Uvicorn

### AI & Memory
- Groq
- Hindsight
